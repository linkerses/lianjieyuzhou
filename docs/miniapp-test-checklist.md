# 小程序联调检查清单

API 地址：`https://api.linkerses.com/api`

## 1. 导入与编译

1. 打开微信开发者工具。
2. 导入项目目录：`apps/miniapp`。
3. 在详情里确认“不校验合法域名”仅用于本地调试；正式体验版需要在微信公众平台配置 `https://api.linkerses.com` 为 request 合法域名。
4. 点击“编译”，确认控制台没有 WXML 表达式错误、路由错误或 request 域名错误。

## 2. 首页

1. 首页能自动开发登录。
2. Agent 摘要、推荐服务、最近交易三个区块能正常加载。
3. “查看全部”服务入口进入服务 tab。
4. “查看全部”交易入口进入交易记录页。
5. 点击推荐服务进入服务详情。

## 3. 服务与预约

1. 服务列表能加载服务卡片。
2. 服务详情展示预演评分、四个维度分、价格、方式、信任信息。
3. 点击预约进入预约页。
4. 日期 picker 选择后显示中文日期标签。
5. 时间 picker 选择后显示时间。
6. 提交预约后跳转交易详情。

## 4. 交易

1. 交易列表三个 tab 可以切换。
2. 交易卡片展示服务名、系统、金额、状态。
3. 点击交易进入详情。
4. 买方/服务方身份显示正确。
5. pending 状态下服务方可确认开始。
6. confirmed 状态下买方可确认完成。
7. completed 状态下买方可提交评分。

## 5. 我的与 Agent

1. “我的”页展示昵称、CID、生命阶段标签。
2. “交易记录”入口进入交易记录页。
3. “信任网络”入口切到 Agent 页的信任 tab。
4. Agent 页可以编辑生命阶段标签，最多选择 3 个。
5. 保存标签后页面状态刷新正常。

## 6. 生产 API 冒烟

在仓库根目录运行：

```powershell
node scripts/smoke-production-api.mjs
```

期望结果：`Smoke test passed: 11/11 checks passed.`

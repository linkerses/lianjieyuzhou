# 小程序体验版上架安排

## 当前结论

当前版本可以进入微信小程序体验版内测。

- API Base: `https://api.linkerses.com/api`
- 小程序 AppID: `wxc0dcea4bac4489ec`
- 生产 API 冒烟结果: `Smoke test passed: 11/11 checks passed`
- 建议体验版版本号: `0.2.1`

## 需要先确认

在微信公众平台完成以下配置：

1. 进入 `开发管理 -> 开发设置 -> 服务器域名`。
2. 在 `request 合法域名` 添加：
   ```text
   https://api.linkerses.com
   ```
3. 保存后等待配置生效。

注意：只填域名，不要填 `/api`。

## 上传体验版

在微信开发者工具执行：

1. 打开项目目录：
   ```text
   D:\BaiduSyncdisk\myobsidian\obsidian\lianjie-agent\apps\miniapp
   ```
2. 确认右上角 AppID 为：
   ```text
   wxc0dcea4bac4489ec
   ```
3. 点击 `清缓存 -> 清除全部`。
4. 点击 `编译`，确认首页、我的 Agent、Agent 广场、服务、交易可打开。
5. 点击顶部 `上传`。
6. 版本号填写：
   ```text
   0.2.1
   ```
7. 项目备注填写：
   ```text
   试用运营版：Agent档案、服务发布、Agent广场、匹配报告、预约交易、运营后台
   ```

## 设置体验版

在微信公众平台执行：

1. 进入 `管理 -> 版本管理`。
2. 找到刚上传的开发版本。
3. 点击 `设为体验版`。
4. 获取体验版二维码。

## 添加体验成员

在微信公众平台执行：

1. 进入 `成员管理 -> 体验成员`。
2. 添加体验者微信号。
3. 保存。
4. 将体验版二维码发给体验成员。

## 内测任务清单

让每个体验成员按顺序完成：

1. 首次进入小程序并授权登录。
2. 完善 Agent 档案：称呼、生命阶段标签、核心价值、服务能力、项目经历、愿景需求。
3. 进入 Agent 广场，查看一个公开档案。
4. 对一个 Agent 生成匹配报告。
5. 发起连接。
6. 浏览服务并预约一次服务。
7. 服务方在工作台或运营后台确认订单。
8. 买方确认完成并评分。

## 暂不正式发布的原因

体验版阶段建议保留：

```env
ENABLE_DEV_LOGIN=true
```

这样便于内部快速切换测试身份。正式发布前再改成：

```env
ENABLE_DEV_LOGIN=false
```

并隐藏或删除小程序里的测试身份切换入口。

## 正式发布前清单

1. 关闭开发登录：`ENABLE_DEV_LOGIN=false`。
2. 删除或隐藏“切换测试身份”入口。
3. 确认微信公众平台合法域名配置完成。
4. 准备服务类目、隐私政策、用户协议。
5. 准备审核截图和功能说明。
6. 提交审核。
